# 用户手册 — PDF 文档问答系统

## 1. 适用范围

本手册对应 `RAG-Q&A system3` 当前实现版本，内容已按现有代码与页面行为整理，不包含未上线功能。

当前版本已经实现：

- 一次上传一个或多个 PDF
- 自动解析 PDF 并建立检索数据
- 知识库管理页面
- 中文问中文答
- 英文问英文答
- 答案引用来源展示

当前版本未实现：

- 首页手动勾选“使用哪个知识库提问”的额外控件

- API 文档：`http://127.0.0.1:8010/docs`

## 3. 首页实际使用方式

### 3.1 上传 PDF

首页底部有上传区和上传按钮。

操作步骤：

1. 点击“上传”区域
2. 选择一个或多个 PDF 文件
3. 点击“上传”按钮
4. 等待系统完成解析

解析完成后，系统会在首页输出框中提示：

- 当前已载入多少份文档
- 当前默认检索范围是哪些文档

### 3.2 当前提问会检索哪些文档

首页当前采用的是简化交互：

- 如果你刚上传了一批 PDF，那么后续提问默认就在这批 PDF 里检索
- 如果系统启动时已经有历史文档，则初始提问范围默认为全部已加载文档

也就是说：

- 首页没有可视化知识库选择器
- 当前版本不需要在页面上再单独指定检索范围

### 3.3 提问

步骤：

1. 在输入框中输入问题
2. 点击“发送”
3. 等待系统返回答案

支持示例：

- 中文：`公司的主营业务是什么？`
- 英文：`What is the company's main business?`

### 3.4 回答展示

首页回答区会展示：

- 回答正文
- 引用文档名
- 引用页码

如果你开启了调试信息，还会显示检索与生成的调试内容。

## 4. 中英文问答说明

当前版本支持自动检测问题语言：

- 中文输入，优先中文回答
- 英文输入，优先英文回答

注意：

- 语言切换已经接入 Query Understanding 和 LLM 回答阶段
- 但检索规则与部分关键词逻辑仍偏中文，因此英文问题的整体稳定性可能弱于中文

## 5. 知识库管理页

知识库管理页地址：

`http://127.0.0.1:8010/kb`

支持以下操作：

- 查看全部文档
- 查看文档总分块数
- 查看某个文档的全部分块
- 删除文档

删除后系统会：

- 删除对应 PDF
- 重新加载剩余文档
- 在后台重新预热检索器

## 6. 当前版本关于“知识库选择入口”的决定

当前版本明确不在首页增加“选择哪个知识库提问”的额外入口。

原因：

- 你前面已经明确指出首页不希望变复杂
- 当前版本优先保证主流程：
  - 上传
  - 解析
  - 提问
  - 返回答案

如果后续确实需要按历史知识库灵活切换，可以走 API：

```http
POST /api/document/select
Content-Type: application/json

{
  "source_files": ["a.pdf", "b.pdf"]
}
```

但这不是当前首页交互的一部分。

## 7. 当前系统实际接口

### 文档相关

- `GET /api/document/status`
- `GET /api/document/warmup`
- `POST /api/document/upload`
- `POST /api/document/reload`
- `POST /api/document/select`

### 问答相关

- `POST /api/query`
- `POST /api/query/stream`
- `GET /api/session/{session_id}`
- `POST /api/feedback`

### 知识库管理

- `GET /api/kb/documents`
- `GET /api/kb/documents/{source_id}/chunks`
- `DELETE /api/kb/documents/{source_id}`

## 8. 常见问题

### 8.1 上传时报 `Field required: file`

通常是浏览器连到了旧服务。

解决办法：

1. 停掉旧服务
2. 重新在 `system3` 目录执行：

```bash
python run.py
```

### 8.2 上传成功但没有解析出内容

常见原因：

- PDF 是扫描件
- PDF 被加密
- PDF 内容为空

### 8.3 为什么英文问题效果有时不如中文

因为：

- 回答语言已经支持英文
- 但检索规则与关键词仍主要围绕中文文档语义构建

所以英文问答是“已支持”，但不是“完全针对英文优化”。
