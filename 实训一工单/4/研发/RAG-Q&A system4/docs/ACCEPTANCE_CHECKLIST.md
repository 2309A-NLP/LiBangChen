# RAG Q&A SYSTEM4 验收清单

思维导图版本见：[ACCEPTANCE_CHECKLIST_MINDMAP.md](./ACCEPTANCE_CHECKLIST_MINDMAP.md)

本文档用于对当前 `RAG-Q&A system4` 项目进行实际验收，重点分为三部分：

1. 功能是否已经实现
2. 实际问答效果是否达到预期
3. 后续应优先优化什么

建议每完成一轮测试，就直接在这份文档里补充结果。

## 1. 验收范围

当前版本建议验收的范围：

- 多 PDF 上传与重载
- PDF 解析与分块
- 知识库文档管理
- 同步问答
- 流式问答
- 会话历史
- 引用来源展示
- 中文提问 -> 中文回答
- 英文提问 -> 英文回答
- 检索预热与系统就绪状态

当前版本默认不在验收主范围内的内容：

- 首页手动知识库切换控件
- 扫描件 PDF 的 OCR 能力
- 企业级评测看板

## 4. 质量验收标准

建议基线如下：

- 功能通过率至少达到 `90%`
- 核心路径项 `F-03`、`F-05`、`F-11`、`F-12`、`F-17` 应达到 `100%`
- 上传、检索、答案生成三条核心链路不能有阻塞性问题
- 不能长期出现“答案和引用明显不一致”的情况

建议问题分级标准：

- `阻塞级`：系统无法用，或核心流程中断
- `严重级`：核心业务问题无法稳定回答
- `一般级`：能用，但效果或体验明显不理想

## 7. 失败分析模板

当某道题测试失败时，可以在这里登记。

| 失败编号 | 问题编号 | 出问题阶段 | 现象 | 怀疑原因 | 严重程度 | 处理动作 |
|----------|----------|------------|------|----------|----------|----------|
| | | 解析 / 检索 / 重排 / 生成 / 引用 | | | | |

阶段说明：

- `解析`：PDF 抽取或分块有问题
- `检索`：正确片段没有召回出来
- `重排`：正确片段召回了，但排序太靠后
- `生成`：证据有了，但最终答案没答好
- `引用`：答案还可以，但引用片段不准或误导

## 8. 优化优先级看板

测试结束后，把问题归到下面三类里。

### P0：交付前必须修复

- 核心流程不可用
- 常见问题出现错误答案且引用误导
- 上传成功但文档不可检索
- 多文档检索明显串文档

### P1：建议优先优化

- 财务表格类问题不稳定
- 英文问题明显弱于中文
- 澄清逻辑触发不稳定
- 预热或首问延迟过高

### P2：可以继续增强

- 首页提示信息更清楚
- 分块预览格式更友好
- 调试信息展示更适合内部测试
- 文档命名、说明、乱码问题清理
